# TrustData 算法设计与实验方法

## 决策对象

对记录 (r) 在业务场景 (s) 下输出：

\[
\mathcal{O}(r,s)=\{\mathbf{v}_r, DTS_{r,s}, coverage_r, uncertainty_r, tier_r, action_r\}
\]

其中可信向量 \(\mathbf{v}_r=[P,B,C,X,T]\) 的各分量范围为 0–100。

## 五维证据

| 维度 | 含义 | 当前可计算信号 | 防止误读 |
|---|---|---|---|
| P | Provenance 来源 | 元数据完整性、来源存在、账户可验证性 | 来源缺失提高不确定性，结论需结合其余证据 |
| B | Behavior 行为 | 发布频率、极端评分比、实体集中度、短时爆发、账户年龄 | 账号年龄采用弱权重，与其余行为证据联合解释 |
| C | Content 内容结构 | 精确/模板重复、文本长度、词汇结构 | 输出重复与模板风险，生成来源由独立流程判断 |
| X | Cross-source 跨源一致性 | 相对跨源参考的评分偏差、平台分歧 | 少数意见作为差异信号，与其他维度联合解释 |
| T | Temporal 时间结构 | entity-day / global-day 稳健突发分数 | 真实热点可突发，必须保留人工复核 |

### 覆盖感知 DTS

场景权重 \(w_{s,k}\) 在配置文件中公开，且和为 1。对可用维度集合 \(A_r\) 重新归一：

\[
DTS_{r,s}=\frac{\sum_{k\in A_r}w_{s,k}v_{r,k}}{\sum_{k\in A_r}w_{s,k}}
\]

覆盖度由可用权重质量计算；不确定性结合覆盖损失、维度分歧和来源弱度。DTS、coverage 与 uncertainty 共同构成结果解释。

## 风险检测层

MVP 使用可解释逻辑回归汇总 P/B/C/X/T 及缺失指示。该选择服务于竞赛阶段的四项验证要求：

- 概率输出和系数可审计；
- 可做固定阈值、校准误差和公平性检查；
- 与规则、单维模型形成清晰基线；
- 为后续 GNN 和时序模型提供统一评测协议，使比较依据落在数据划分、误伤率和下游稳定性上。

验证阈值在验证集以低误伤约束锁定为 0.90。当前同时记录 Brier score 与 ECE；结果显示概率校准仍有限，模型概率用于表达相对风险，现实发生概率需要平台标注校准。

## 受控污染基准

- 清洁池：100,000 条记录；8,000 个贡献者；2,000 个实体；180 天。
- 分布播种：实体参考来自 4,102 个跨源对齐实体；评论文本来自已发表摘录，只承担文本多样性作用。
- 五类攻击：评分操纵、协同账户、重复内容、时间突发、来源缺失；每类生成 6,000 条，总注入池 30,000 条。
- 污染强度：1%、5%、10%、20%、30%。
- 训练/验证/测试：StratifiedGroupKFold 形成贡献者隔离划分；各污染档共享稳定分组映射。
- 随机性控制：主运行种子和五个贡献者分组敏感性种子记录在 `configs/trust.yaml`。

## 指标体系

1. 分类：Precision、Recall、F1、FPR、FNR、AUROC、AUPRC。
2. 概率：Brier、ECE。
3. 排序：Spearman、Kendall、Top-100 overlap、mean rank error、NDCG。
4. 解释：P/B/C/X/T 消融。
5. 公平性护栏：按账户年龄分组的清洁样本 FPR。
6. 可复现：输入、配置、输出哈希，环境版本，随机种子与运行时间。

## 分组敏感性协议

主结果使用固定贡献者隔离划分。稳健性检查保持同一受控数据生成实例、特征、模型族和阈值规则，使用五个分组种子重新生成 train/validation/test 划分；每次均在验证组按 FPR 约束锁定阈值，并在测试组报告 F1、AUPRC 与 FPR。该协议检验结果对贡献者划分的敏感程度，数据生成机制层面的不确定性由下一阶段独立生成种子实验覆盖。

## 下一代算法路线

### G1：关系图风险编码

构建 contributor–record–entity–time 异构图，使用关系选择和邻域鲁棒聚合识别协同行为。该模块将在取得真实图数据并完成防泄漏评估后加入；合成图结果仅用于方法检查。

### G2：在线变点与群体突发

用稳健 EWMA / Bayesian online change-point 对 entity-time 矩阵报警，输出事件级解释并与热点白名单联动，降低“真实流行事件”误伤。

### G3：不确定性与选择性预测

增加验证集温度缩放、可靠性图和 selective risk–coverage 曲线；高不确定记录进入人工复核，阈值随场景成本校准。

### G4：场景权重学习

从平台的复核成本、误伤成本、榜单稳定性和人工容量学习场景权重，同时保留权重上限与审批记录。当前 MVP 使用公开的政策参数；外部标定列入平台试点。

### G5：隐私与跨平台协同

以实体级统计、签名来源声明和风险模式支持跨平台协同，原始用户数据保留在来源平台。联邦学习与隐私计算列入路线图。
