# 用户评价数据可信评估与分级解决方案

## 1. 解决方案定位

本项目应定位为面向众包内容平台的数据治理与决策支持解决方案，而不是一个通用消费端产品。

解决的核心问题不是判断用户“喜欢还是不喜欢”，而是回答：

1. 一条评价在数据质量、行为模式、内容证据和群体一致性上有多可信；
2. 哪些异常信号导致可信度下降；
3. 该评价应正常使用、降低权重、进入复核还是隔离；
4. 可信度修正后，内容、作品或商家的聚合评价应如何变化；
5. 评估结果能否被复现、解释、审计和回溯。

## 2. 适用对象

- 平台数据治理与风控人员；
- 推荐、搜索和排序算法团队；
- 内容运营和人工审核人员；
- 研究人员、课程设计或毕业设计评审；
- 需要使用众包评价数据进行分析的第三方机构。

## 3. 解决方案边界

### 包含

- 评价数据接入与标准化；
- 数据质量检测；
- 行为、内容、来源和群体信号计算；
- 可信度评分与分级；
- 风险原因解释；
- 分级处置建议；
- 聚合评分稳健性分析；
- 离线实验、模型比较和可视化报告；
- 结果版本、阈值和实验记录。

### 不包含

- 对用户人格、动机或现实身份作结论；
- 仅凭单一模型自动封禁用户；
- 使用受保护属性进行风险判断；
- 把统计异常直接等同于恶意行为；
- 未经验证即承诺跨平台实时生产能力。

## 4. 当前原型与目标解决方案

| 层级 | 定义 | 交付状态判定 |
|---|---|---|
| M0 概念 | 只有问题与方法描述 | 无可运行结果 |
| M1 实验原型 | 可采集/读取数据、运行离线实验、展示结果 | 当前仓库需审计确认 |
| M2 可演示解决方案 | 一键运行、标准输入输出、解释与处置闭环、完整演示脚本 | 本轮补全目标 |
| M3 试点方案 | 可接客户样本、可配置阈值、可审计、具备质量监控 | 后续演进方向 |
| M4 生产产品 | 多租户、权限、在线服务、SLA、持续训练与运营后台 | 不作为当前承诺 |

## 5. 端到端工作流

```text
原始评价/评分/用户行为/对象信息
    ↓
数据接入与字段映射
    ↓
完整性、合法性、重复与来源检查
    ↓
行为/内容/群体/时序/来源特征计算
    ↓
规则基线 + 统计/机器学习模型
    ↓
可信分数 + 等级 + 风险标签 + 证据
    ↓
正常采用 / 降权 / 人工复核 / 隔离
    ↓
稳健聚合、效果评估、审计与回溯
```

## 6. 标准输出

每条被评估记录至少输出：

```json
{
  "record_id": "review_001",
  "assessment_version": "v1.0.0",
  "credibility_score": 82.5,
  "credibility_grade": "A",
  "confidence": 0.86,
  "risk_flags": [],
  "dimension_scores": {
    "data_quality": 91,
    "behavior": 79,
    "content": 84,
    "consensus": 76,
    "source": 88
  },
  "evidence": [
    {
      "code": "HISTORY_STABLE",
      "message": "历史评价行为稳定",
      "contribution": 8.2
    }
  ],
  "recommended_action": "ACCEPT",
  "assessed_at": "2026-08-29T00:00:00+08:00"
}
```

分数、等级、置信度必须分开：分数表示当前模型判断，置信度表示证据是否充分，等级用于业务处置。

## 7. 分级与处置基线

以下为可配置的初始基线，不应在没有标注数据的情况下宣称为最终最优阈值：

| 等级 | 初始分数区间 | 含义 | 建议处置 |
|---|---:|---|---|
| A | 80–100 | 高可信且证据较充分 | 正常采用，可进入聚合 |
| B | 65–79 | 基本可信，存在轻微不确定性 | 正常采用或轻度降权 |
| C | 45–64 | 证据不足或存在明显异常 | 降权并进入抽样复核 |
| D | 0–44 | 高风险或数据质量不合格 | 隔离，不直接参与聚合 |

低置信度记录应优先标记为“证据不足”，而不是直接判定为低可信。

## 8. 使用场景

### 场景 A：评价排序与展示

在相关性、时效性之外增加可信度信号，使高证据、高质量评价更容易被展示。

### 场景 B：聚合评分修正

比较原始均值、截尾均值、可信度加权均值和贝叶斯/稳健估计，展示异常评价对总体得分的影响。

### 场景 C：异常评价复核

按风险标签、影响范围和证据充分程度生成审核队列，不把模型得分直接当作处罚结论。

### 场景 D：平台数据质量报告

输出完整率、重复率、异常集中度、等级分布、时间漂移和高影响风险样本。

### 场景 E：研究与算法比较

在同一数据划分、同一指标和同一阈值选择规则下比较规则法、统计法和机器学习方法。
