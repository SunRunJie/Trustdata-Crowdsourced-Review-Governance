# 产品架构与交付说明

## 工作流

```mermaid
flowchart LR
    A[来源快照与许可] --> B[标准化与实体对齐]
    B --> C[P/B/C/X/T 特征层]
    C --> D[可信向量与覆盖度]
    D --> E[场景化 DTS]
    E --> F[等级与治理动作]
    F --> G[可信护照 / 人工队列]
    G --> H[审计、反馈与再校准]
```

## 产品工作面

| 页面 | 决策任务 | 主要输出 |
|---|---|---|
| 治理总览 | 判断当前数据资产风险和人工容量 | 数据规模、检测结果、等级分布、复核量 |
| 可信护照 | 解释单条记录为何被分级 | P/B/C/X/T、DTS、覆盖、不确定性、动作 |
| 风险监测 | 检查风险与误伤护栏 | 阈值、AUPRC/F1/FPR、账号年龄 FPR |
| 治理队列 | 分配人工复核 | D/E 样例、风险分、动作建议 |
| 审计追溯 | 回答“数字从哪里来” | 数据快照、配置、运行、阈值和版本链 |
| 基准验证 | 审查效果与失败场景 | 五档污染、排序稳健性、限制与证据等级 |

## 技术实现

- 数据与算法：Python 3.12、pandas、NumPy、SciPy、scikit-learn、Matplotlib、PyYAML。
- 产品原型：本地 HTML/CSS/JavaScript，直接读取 `app/data/dashboard.json`。
- 配置：`configs/trust.yaml` 保存随机种子、污染规模、场景权重和等级阈值。
- 输出：CSV/JSON/PNG + SHA-256 运行清单。
- 安全：原型采用人工复核模式，输入限于脱敏研究数据，处置结果保持可撤销。

当前产品采用本地静态交付，适合竞赛演示、离线审查和试点沟通。公开部署阶段将增加身份认证、租户隔离、接口限流、隐私影响评估和运行监控。

## 本地启动

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/product/#overview`。必须通过本地服务器访问，直接双击 HTML 会受到浏览器跨文件读取限制。

## 生产化接口建议

- `POST /v1/assess/record`：返回单记录 Trust Passport。
- `POST /v1/assess/batch`：批量异步评估，输出批次清单。
- `GET /v1/queue`：按风险、覆盖和场景筛选治理队列。
- `POST /v1/reviews/{id}`：保存人工复核结论与理由。
- `GET /v1/audit/{record_id}`：返回特征、模型、配置和动作历史。

真实平台接口需要配套身份认证、租户隔离、字段脱敏、速率限制、审计存证与删除/更正流程。
