# 3 分钟产品演示脚本

1. 0:00–0:25 治理总览：说明观测数据规模、E2 证据标识和 30% 污染指标；交代结论只适用于数据使用风险评估。
2. 0:25–1:05 可信护照：搜索一条记录，解释 P/B/C/X/T、DTS、覆盖度、不确定性、等级与动作。
3. 1:05–1:35 风险监测：展示验证阈值和不同账号年龄 FPR；说明账号年龄在联合证据中的较低权重。
4. 1:35–2:00 治理队列：说明原型采用人工复核模式，确认结果可反馈到审计链。
5. 2:00–2:25 审计追溯：展示数据快照、阈值锁定、运行版本和哈希思路。
6. 2:25–3:00 基准验证：展示五次贡献者分组复算、1% 污染失败与 20%–30% 排序改善，收束为“让平台知道何时自动化、何时转人工”。

录制要求：画面使用实际本地页面；功能展示与运行产物逐项对应；客户和第三方信息以正式凭证为依据；末页显示证据等级和运行清单。
